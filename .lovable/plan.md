# 수강반 이름(내신) · 영상 제목(정규) 형식 통일

DB 구조는 바꾸지 않고, 기존 데이터를 자동으로 일괄 변환하지도 않습니다.

## 1. 내신 수강반 이름
- 형식: `[교육원] 기수 - 학교(또는 출판사) - 내신` (예: `[상동] 19기 - 송도고 - 내신`)
- 생성 폼과 상세 설정 탭에서 유형을 '내신'으로 고르면 이름 입력칸 대신 클릭으로 고르는 화면이 나옵니다.
  - 교육원 칩(상동/청라/송도), 기수 칩(19기~13기)
  - 학교/출판사 토글: 학교는 고른 교육원의 학교 목록(검색 가능), 출판사는 출판사 칩
  - 완성될 이름을 실시간으로 미리 보여주고, 다 고르기 전에는 저장 버튼이 꺼져 있습니다.
- 기존 이름이 형식에 맞으면 선택 상태를 그대로 불러오고, 맞지 않으면 "형식 미준수" 경고를 띄웁니다. 다시 고르면 새 이름으로 덮어씁니다.
- 공개 교육원은 고른 교육원으로 자동 설정됩니다.
- 정규 반의 이름은 지금처럼 자유롭게 입력합니다.

## 2. 정규 수강반의 영상 제목
- 일반 과목: `[n월 n주차] 과목 - 내용` / 어휘: `어휘 n강`
- 업로드 화면(Vimeo·YouTube 모두)과 영상 관리의 제목 수정에서, 정규 반 영상일 때만 표시합니다.
  - 과목 칩(어휘 포함)
  - 어휘가 아니면: 월(1~12)·주차(1~5) 칩과 내용 입력칸(필수). 기존 주차 값이 있으면 기본값으로 채우고, 저장할 때 주차(올해 기준)도 함께 맞춥니다.
  - 어휘이면: 강 번호(1~30)만 고르고, 주차 값은 건드리지 않습니다.
  - 완성된 제목 미리보기, 200자 제한
- 기존 제목이 형식에 맞으면 불러오고, 맞지 않으면 "형식 미준수"로 표시합니다.
- 내신 반 영상 제목은 지금처럼 자유롭게 입력합니다.

## 3. 공통
- 수강반 목록과 영상 목록에 "형식 미준수" 배지와 필터를 추가해, 기존 데이터를 하나씩 눌러 고칠 수 있게 합니다.
- 서버에서도 형식을 검사해 맞지 않는 저장 요청은 거부합니다(새로 만들거나 수정할 때만 해당하며, 기존 데이터는 그대로 둡니다).

## 기본값으로 정한 것(바꾸고 싶으면 알려주세요)
- 출판사 목록: 능률, 천재(노), 천재(정), 비상, 동아, 미래엔, 지학사, 창비, 금성, 해냄, 좋은책신사고
- 과목 목록: 문법, 문학, 독서, 어휘, 화법과작문, 언어와매체, 서술형
- 정규 영상의 월/주차 미리보기는 `[8월 1주차]`처럼 연도 없이 표시합니다.

## 기술 세부
- `src/lib/naming.ts`: buildNaesinClassName / parseNaesinClassName / buildRegularVideoTitle / parseRegularVideoTitle과 정규식, zod 검증 헬퍼를 순수 함수로 둡니다.
- `src/lib/publisher.ts`의 PUBLISHER_OPTIONS, `src/lib/subject.ts`의 SUBJECT_OPTIONS를 새로 만듭니다.
- 공용 컴포넌트: `NaesinClassNamePicker`, `RegularVideoTitlePicker` (`src/components/admin/`).
- 수정할 파일: `admin.classes.index.tsx`, `admin.classes.$id.tsx`, `VideoUploadForm.tsx`, `admin.videos.tsx`, `classes.functions.ts`(createClass/updateClass 검증), `vimeo.functions.ts`·`videos.functions.ts`(영상 생성/수정 검증. 대상 반 class_type을 조회해 정규일 때만 검사).
- 학교 목록은 기존 `listStudentFilterOptions`의 schoolsByBranch를 사용합니다.
- 검증 후 `bunx tsc --noEmit`로 타입 검사합니다.
