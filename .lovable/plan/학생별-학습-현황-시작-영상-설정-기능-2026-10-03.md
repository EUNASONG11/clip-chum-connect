# 학생별 "학습 현황 시작 영상" 설정 기능

## 원인 (확인됨)
학습 현황은 학생이 **배정된 시각 이후에 올라온 영상만** 계산합니다.
- 신정우(10/3 11:21 배정), 이건이(10/3 11:22 배정)
- "예비중1 어휘 12강"은 10/3 10:52 등록 → 배정보다 먼저 올라와서 빠짐

## 할 일

1. **학생별 시작 영상 설정 저장**
   - 수강반 배정 정보에 "학습 현황 시작 시점"을 따로 저장할 칸을 추가 (비어 있으면 지금처럼 배정 시각 기준)
   - 설정하면 선택한 영상이 올라온 시점부터 이후 영상이 모두 학습 현황에 포함

2. **학습 현황 계산 반영**
   - 수강반 학습 현황, 기간별 학습 현황, 학생 상세 학습 이력이 이 설정값을 우선 사용

3. **강사용 설정 화면** (수강반 상세 > 배정된 학생 목록)
   - 학생마다 "시작 영상" 버튼 → 수강반 영상 목록(등록순, 주차·폴더 표시)에서 선택, "배정 시점으로 되돌리기" 가능
   - 여러 학생 체크 후 한 번에 설정하는 일괄 설정 버튼
   - 권한: 최고 관리자, 중간관리자, 그 수강반 담당 강사

4. **신정우·이건이 즉시 적용**
   - 두 학생의 시작 영상을 "예비중1 어휘 12강"으로 설정

## 기술 세부
- 마이그레이션: `class_students.progress_start_at timestamptz NULL` 추가, `class_student_stats_agg` / `_range`의 `st.start_at`을 `COALESCE(cs.progress_start_at, e.start_at)`로 재정의
- `getStudentLearningDetail`의 `start` 계산도 동일 규칙
- 서버 함수 `setStudentProgressStart({classId, userIds[], videoId|null})` — `assertOwnClassOrAdmin`(쓰기 권한)으로 검증, 영상의 `created_at`을 저장
- 데이터: 두 학생(user_id 8ba03c77…, f67bf467…)의 19기 배정 행에 12강 `created_at` 저장
